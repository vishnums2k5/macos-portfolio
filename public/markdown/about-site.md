# About This Site

This site is a personal portfolio crafted in the design language of macOS Tahoe Liquid Glass. It is built using [React](https://reactjs.org/), [Zustand](https://zustand-demo.pmnd.rs/), [UnoCSS](https://uno.antfu.me/), and [Vite](https://vitejs.dev/).

It simulates a full macOS desktop experience with interactive system apps including Finder, Terminal, Safari, Notes, App Store, System Settings, Siri, and widgets.
