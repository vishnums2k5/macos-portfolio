# AudioFlow – Modern Android Music Streaming & Player

**Android Application** | **Media & Mobile Engineering**

* **GitHub Repository:** [vishnums2k5/AudioFlow](https://github.com/vishnums2k5/AudioFlow)
* **Tech Stack:** Kotlin, Jetpack Compose, AndroidX Media3 (ExoPlayer), Dagger Hilt, Coroutines & Flow, Room DB, WorkManager, OkHttp

---

### Overview

A full-featured modern Android music streaming app built with Jetpack Compose and Media3 ExoPlayer, supporting ad-free YouTube Music streaming, offline caching, synchronized lyrics, and dynamic UI theming.

### Key Features

* **Modern Jetpack Compose UI:** Material 3 design system with dynamic palette extraction and smooth transitions.
* **ExoPlayer & Background Service:** Foreground media playback service with notification controls and headset hooks.
* **Offline Caching:** High-speed stream caching with Room database indexing for uninterrupted playback.
* **Time-Synced Lyrics:** Real-time synchronized lyric scrolling.
