### Overview

Repeat is a full-stack DSA preparation and spaced-repetition platform designed to conquer the forgetting curve for coding interviews. It automatically schedules problem reviews at 1, 3, 7, and 21-day intervals, syncs accepted LeetCode submissions in real time via a custom Chrome extension, and keeps users accountable with Telegram reminders, GitHub-style activity heatmaps, and a competitive leaderboard.

### Key Features

* **Automated Leitner Intervals:** Automatic review queues at 1, 3, 7, and 21 days.
* **Chrome Extension Sync:** Automatically tracks accepted LeetCode problem submissions without manual logging.
* **Accountability Bot:** Telegram reminders and notifications keep you on track.
* **Analytics & Heatmaps:** GitHub-style submission activity graphs and community leaderboard.
