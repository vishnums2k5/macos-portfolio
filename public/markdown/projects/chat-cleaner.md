### Overview

Lets you bulk-select, archive, and delete AI chat history across 14+ platforms from one place. Integrates directly with each platform's own API for near-instant bulk actions, with a privacy-first design — no accounts, no data collection.

### Key Features

* **14+ Supported Platforms:** Clean up chats across major LLM interfaces.
* **Direct API Integration:** Fast, bulk actions performed directly with platform endpoints.
* **Privacy-First:** Zero accounts, zero tracking, and zero data collection.
