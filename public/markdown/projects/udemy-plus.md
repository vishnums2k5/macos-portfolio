---

### Overview

Udemy+ — A feature-packed Chrome extension that turns Udemy into a pro learning platform with custom video controls, OCR code extraction, automated spaced repetition, and GitHub-style study analytics.

### Key Features

* **Custom Video Controls & Audio Boost:** Granular playback speed, pitch control, and Web Audio amplification.
* **On-Screen OCR:** Extract code and text directly from paused video frames using Tesseract.js.
* **Automated Spaced Repetition:** Remember course concepts with scheduled review intervals.
* **Study Analytics:** GitHub-style activity contribution heatmaps to visualize learning streaks.
