---

### Overview

A productivity web app that helps users create habits, track daily progress, and stay consistent over time. Built with vanilla JavaScript and a fully responsive interface for a smooth, intuitive tracking workflow.

### Key Features

* **Daily Streak Tracking:** Intuitive streak counters and progress markers.
* **Zero Dependencies:** Ultra-lightweight and fast performance powered by Vanilla JS.
* **Persistent Local Storage:** Habit data is saved seamlessly right in the browser.
