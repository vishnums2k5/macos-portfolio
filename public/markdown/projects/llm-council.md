---

### Overview

A productivity extension that sends one prompt to every open AI chat tab (ChatGPT, Gemini, Claude, etc.) at once — no API keys required. An AI Judge automatically scores and ranks each response, and one-click export supports PDF, PNG, Markdown, HTML, and plain text.

### Key Features

* **Multi-Tab Broadcast:** Send single prompts across multiple open AI chats simultaneously without needing API keys.
* **Automated AI Judge:** Automatically evaluates, scores, and ranks responses side-by-side.
* **One-Click Export:** Download evaluations and conversations as PDF, PNG, Markdown, HTML, or raw text.
