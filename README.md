# Vishnu M S — macOS Portfolio

> **"Code. Ship. Repeat."**  
> Building AI-powered tools people actually use — from native macOS apps to open source infrastructure.

A personal web portfolio recreating the macOS Tahoe Liquid Glass user experience in the browser. Featuring an interactive operating system with desktop apps, Launchpad, Finder, Terminal, Safari, Notes, App Store, and Siri assistant.

Built with [React](https://reactjs.org/), [Zustand](https://zustand-demo.pmnd.rs/), [UnoCSS](https://uno.antfu.me/), [TypeScript](https://www.typescriptlang.org/), and [Vite](https://vitejs.dev/).

* **[LLM Council - Compare AI Responses](https://chromewebstore.google.com/detail/llm-council-compare-ai-re/agnfmnfjhehoooaagjlbpdkkibjfaage)** — Productivity extension broadcasting prompts across open AI tabs with automated AI ranking and multi-format exports.
* **[Universal Chat Cleaner](https://chromewebstore.google.com/detail/universal-chat-cleaner-bu/dlkglncfoaegojplnhalffbgagnailcb)** — Bulk-select, archive, and delete AI chats across 14+ platforms with privacy-first design.

* **[ChessWise](https://chesswise-web.vercel.app/)** — AI chess coach pairing Stockfish 18 evaluations with Gemini and RAG blunder drills.
* **[Repeat](https://dsa-tracker-repeat.vercel.app/dashboard)** — Full-stack DSA spaced-repetition platform syncing LeetCode submissions.

## 💻 Local Development

```bash
# Install dependencies

# Build production bundle
pnpm build

# Preview build locally
pnpm serve
```
